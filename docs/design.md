# CodeWise2 interface decisions

CodeWise2 is a study instrument: compact navigation, a quiet reading surface and a coding workspace with explicit task actions. The original visual identity uses a paired-bracket mark, indigo actions and neutral slate surfaces. Warm off-white light mode is independently tokenized. No remote fonts, analytics or decorative stock images are required.

Spacing follows a four/eight pixel rhythm, with 10–16 pixel radii. Interface text uses the system sans-serif family; code uses Cascadia Code, SFMono-Regular and monospace fallbacks. Lessons use 17 pixel text with 1.7 line height and a comfortable maximum width. Semantic status labels always accompany color.

The responsive workspace uses two resizable panes on laptops, an optional tutor drawer, and explicit Problem/Code/Results/Tutor tabs on narrow screens. Sidebar navigation collapses on narrow screens. Splitters support keyboard arrows. Roadmap zoom is bounded, with a fit action and equivalent list view.

Loading, unsaved drafts, unavailable execution, no-key tutoring, empty history and interrupted answers are first-class states. The interface reports server evidence only. Markdown rendering disables raw HTML and external images; mathematical rendering disables trusted input features. Code copy and local export do not contact an AI provider.
