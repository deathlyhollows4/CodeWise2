# Checkpoint practice readiness

Decision: 2026-10-08, coordinator and backend/frontend reviewers. Implementation belongs to the versioned `learning-3` engine; test evidence must close the decision separately.

An accepted assisted solve introduces concepts without proving independent mastery. A different question at the same step can test those concepts. Requiring an earlier independent demonstration of the exact concept being tested creates a circular prerequisite: for example, assisted tree-node counting could make the related leaf-total checkpoint unavailable even though that checkpoint is the intended independent test of child traversal.

For an unseen, related, same-step checkpoint following an actually accepted assisted source, a prerequisite may be considered ready to practise only when it is explicitly among the skills taught/tested by both the source question and the checkpoint. This is a narrow eligibility rule. It does not add known skills, independent evidence, mastery or advancement. It never relaxes eligibility for a harder next-step question. Real prerequisites outside that shared tested set still require an independently completed teacher.

Authors must declare skills truthfully from each task's actual work. Mechanically adding the union of neighboring skill IDs to pass an audit is prohibited. Incorrect prerequisite classifications may be corrected with a written pedagogical reason; legitimate prerequisite requirements must remain.

When prerequisite practice is necessary, persist the original focus, source, requested step and `same_step_checkpoint` intent through navigation, refresh, backup and restart. Completing a cross-topic teacher returns to the intended original checkpoint. Only an actual independent acceptance of a new checkpoint can request the next harder step.

The recommendation should explain that the learner is practising a concept introduced with help, and that this is not yet independent mastery. The audit must distinguish this valid checkpoint practice from missing external prerequisites, already-exposed or already-solved repeats, absent content, and exhausted paths.

Required evidence: shared introduced-skill access, unrelated/untaught skill rejection, no harder-step relaxation, exposure/repeat exclusion, no mastery change on selection, durable prerequisite bridge return, and independent checkpoint advancement. This decision does not itself certify those tests or the full curriculum.
