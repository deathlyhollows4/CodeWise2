Each row of items is [weight,value] for one distinct item. Choose any subset of items whose total weight is at most capacity, and return the greatest possible total value. You may use each item at most once. Equal rows still represent separate items. A zero-weight item can be chosen once and contributes its value without using capacity. Choosing no items is permitted and has value 0. Item order does not affect the result. Return a 64-bit integer in Java/C++, since the best value can exceed a 32-bit integer. This task optimizes value; you do not need to fill capacity exactly or return the chosen items.
