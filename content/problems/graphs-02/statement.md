Vertices are numbered 0 through n-1. Each edges row [u,v] is one directed edge from u to v. Return an array of length n: entry v is the number of distinct routes from vertex 0 to v that use the fewest edges, modulo 1000000007. Parallel edge rows are different edge choices and can create different routes; self-loops are permitted. Unreachable vertices have count 0. Vertex 0 has count 1 for its empty route, regardless of loops or cycles. For n=0, edges is empty and return []. A route that reaches a vertex with extra hops must not contribute to its shortest-route count. Edge-list order does not matter.
