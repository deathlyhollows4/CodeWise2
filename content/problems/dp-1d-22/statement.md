There are n distinct labelled items and n distinct positions, both numbered 0 through n-1. Count permutations of the items into the positions for which no item appears in its original position. Every item appears exactly once and every position receives exactly one item. Return the count modulo 1000000007. The empty permutation is valid, so n=0 returns 1; n=1 returns 0. Labels are fixed by n and are not an input list: changing their names does not create extra test inputs or extra permutations. This asks for the number of derangements, not all permutations, assignments that merely move at least one item, or an explicit enumeration.
