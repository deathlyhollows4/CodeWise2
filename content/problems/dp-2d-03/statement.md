Given two integer sequences a and b, return the greatest length of a sequence obtainable from each by deleting zero or more positions. Remaining positions must keep their original order, but do not need to be consecutive. Equality means equal integer values; repeated equal values at different positions remain separate positions. Return only the length, not a chosen subsequence or the number of choices. Either sequence may be empty, giving 0. For example, deleting the middle value of [4,9,4] leaves [4,4]. Changing the sequence order is not permitted.
