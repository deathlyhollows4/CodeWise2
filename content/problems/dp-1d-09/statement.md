A paragraph has indivisible words with the given lengths, in input order. Put consecutive words onto lines of width at most width. Put exactly one space between neighboring words on the same line, with no leading or trailing spaces. A nonlast line costs the square of its unused width. The final line costs 0 regardless of unused width. Return the smallest total cost over every valid line-break choice. If any word cannot fit even on a line by itself, return -1. An empty paragraph returns 0. Return a 64-bit value because squared gaps can create a large total.
