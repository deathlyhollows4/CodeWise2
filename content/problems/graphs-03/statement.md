An undirected graph has vertices 0 through n-1. Each edges row [u,v] connects u and v in both directions. Return the number of connected components. Two vertices are in the same component when an edge path joins them. Isolated vertices each form their own component. The empty graph returns 0. There are no self-loops or duplicate undirected edges. Edge order and swapping the two endpoints of an edge do not change the graph.
