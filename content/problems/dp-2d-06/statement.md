Return true if ASCII string target can be formed by merging ASCII strings a and b. Use every source character exactly once, preserve the order of characters from a, and separately preserve the order from b. At each output position, you may take the next unused character from either source. Equal characters can come from either source; choosing one too early may block a later match. The target length must equal a.length+b.length, or the answer is false. Empty sources are permitted. Matching is literal and case-sensitive, including spaces, punctuation and control characters. Do not merely compare character frequencies.
