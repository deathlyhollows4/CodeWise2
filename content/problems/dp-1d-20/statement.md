The strictly increasing array days contains the calendar dates on which travel is required, from day 1 through day 365. costs contains the positive prices of 1-day, 7-day and 30-day passes, in that order. A pass bought for day d is valid on every calendar day from d through d+duration-1, inclusive. You may buy any number of passes; overlapping coverage is allowed. Cover every required travel date and return the smallest total price. Dates without travel do not need coverage. Empty days requires no purchases and returns 0. Duration counts consecutive calendar days, not a number of entries in days. Pass prices need not increase with duration, so never assume a longer pass is more expensive.
