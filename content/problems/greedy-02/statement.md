Stations are indexed 0 through n-1 around a circle. gas[i] is the fuel collected at station i; cost[i] is the fuel required to travel from i to (i+1) modulo n. Start with an empty tank, collect the fuel at the chosen start, and travel in increasing circular index order for exactly n legs. The tank has unlimited capacity and must never become negative after a leg. Return the smallest station index that can complete the circuit, or -1 if none can. Empty input returns -1 because no starting station exists. Fuel and costs are nonnegative; zero is permitted. If several starts work, the smallest index is required. An overall nonnegative fuel balance alone does not identify a valid start.
