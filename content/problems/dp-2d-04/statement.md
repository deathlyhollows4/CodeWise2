Return the fewest single-character edits needed to transform ASCII string a into ASCII string b. One edit inserts one character anywhere, deletes one character, or replaces one character with another. Each edit costs 1. Matching characters cost 0. Reordering or swapping two characters is not an allowed single edit. Characters match literally and case-sensitively, including spaces, punctuation and control characters. Either string may be empty. Return the minimum edit count, not the edited string or a list of operations.
