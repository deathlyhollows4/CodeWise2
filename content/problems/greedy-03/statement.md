Children stand in the order of ratings. Give every child a positive integer number of candies. If a child has a higher rating than an immediate neighbor, that child must receive strictly more candies than that neighbor. Equal ratings impose no candy ordering. Return the smallest possible total number of candies. Empty input returns 0. Only immediate neighbors impose constraints; a higher rating than a distant child creates no direct condition. Both left and right neighbors matter. You return the total, not an allocation list, and must use a 64-bit total for long monotone lines.
