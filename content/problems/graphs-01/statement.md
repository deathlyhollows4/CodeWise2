You receive a native GraphNode root named graph. Every node has val=0 and an ordered neighbors list. Traverse breadth-first: give root index 0, scan discovered nodes in their discovery order, and inspect each neighbors list from first to last. Give each previously unseen node identity the next index immediately when it is first encountered. Return a square integer matrix where entry [i][j] is the number of occurrences of node j in node i's neighbors list. This is a directed count, not merely a boolean edge. Self-loops and repeated neighbors are permitted. Every input node is reachable from root. A null root returns an empty matrix. Do not change any original value or neighbor list. Two different nodes both have value 0 and must remain different identities. The JSON node-table representation is handled by the harness; your function works with native nodes.
