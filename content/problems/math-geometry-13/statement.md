Return the vertices of the smallest convex region containing every point. Remove duplicate points and omit points that lie strictly between other points on a hull edge. For a nondegenerate hull, return vertices counterclockwise, starting with the lexicographically smallest [x,y] pair. If all unique points are collinear, return just the two extreme points in lexicographic order. A single unique point returns one pair; an empty set returns an empty array.
