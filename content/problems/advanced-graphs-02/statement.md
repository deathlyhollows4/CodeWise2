Vertices 0 through n - 1 have unknown integer potentials p[0]..p[n - 1]. Each row [u,v,delta] requires p[v]-p[u]=delta. Return true if some integer assignment satisfies every row at once, otherwise false. Absolute potential values are not bounded; shifting every potential in one component by the same constant changes no equation. Disconnected components can be assigned separately. A self-equation [u,u,delta] is consistent exactly when delta=0. Repeated equations may agree or contradict. An empty equation set, including n=0, is consistent. Do not treat these rows as shortest-path distances or ignore their direction. Use wide signed offsets in Java/C++; consistent chains can imply potentials beyond 32-bit range.
