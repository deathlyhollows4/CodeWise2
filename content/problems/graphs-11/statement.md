An undirected graph has vertices 0 through n-1. Row edges[id]=[u,v] is original edge id. Return the IDs of every bridge, in increasing numeric order. A bridge is an edge whose removal alone increases the number of connected components in the whole graph. The graph may already be disconnected. There are no self-loops or duplicate undirected edges. Isolated vertices are components but do not create bridge IDs. Swapping an edge's endpoints does not change its connectivity; row positions still determine original IDs. The empty graph returns [].
