Choose a subsequence of values by deleting any number of elements without changing the order of the elements kept. For every consecutive pair kept, the difference must be nonzero, and the signs of consecutive differences must alternate positive, negative, positive, negative or the reverse. Return the longest possible number of elements kept. Empty input returns 0; a single kept element is valid and has length 1. Two distinct kept elements are valid. Equal adjacent kept values are not valid, but equal input values may be skipped. This is a subsequence, not necessarily a contiguous segment; it need not start by rising. Strictly increasing input of length at least 2 has answer 2 rather than its increasing-subsequence length.
