A rectangular grid uses 0 for an open cell, 1 for a wall, and 2 for a source. Moving up, down, left, or right between non-wall cells costs one step. Return a matrix of the same shape: a wall gets -2; any other cell gets its minimum number of steps from any source, or -1 if no source can reach it. Every source has distance 0. You may pass through another source. There may be zero, one, or many sources. Diagonal moves are forbidden. Empty input returns []; a grid with empty rows returns equally many empty output rows.
