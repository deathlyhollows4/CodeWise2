Count the nonempty contiguous substrings of text that read the same forward and backward. Count by index interval: equal substring text occurring at different positions counts separately. Single characters count, as do both odd-length and even-length palindromes. The empty text returns 0. Matching is literal and case-sensitive for ASCII characters, including spaces and punctuation. This asks for the number of palindrome occurrences, not the number of distinct palindrome strings or the longest palindrome length.
