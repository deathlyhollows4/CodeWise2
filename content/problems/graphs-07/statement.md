Vertices are numbered 0 through n-1. Each edges row [u,v] is an undirected edge. Return true exactly when every vertex can receive one of two colors so that each edge joins vertices with different colors. Check all components, including disconnected ones. A self-loop makes the answer false because a vertex cannot have a color different from itself. No duplicate undirected edges occur. Isolated vertices can have either color. The empty graph returns true. Return only whether a coloring exists, not one particular coloring.
