Vertices 0 through n-1 form a directed graph. Partition all vertices into strongly connected components: two vertices belong to the same group exactly when each can reach the other through directed edges. A vertex reaches itself by an empty path, so every vertex belongs to a group even if it has no edges. Return an array of groups. Sort vertex IDs increasingly inside each group, and sort the groups by their first vertex ID. Include every vertex exactly once. Self-loops are permitted; duplicate directed edges are not. The empty graph returns []. A one-way edge between groups does not merge them.
