Vertices 0 through n - 1 form a directed graph. Each row [u,v,cost] is an edge from u to v with an integer cost that may be negative. Start at vertex 0. For every vertex, return one string in vertex order: its minimum total walk cost as a canonical decimal integer string, UNREACHABLE if no walk from 0 reaches it, or UNBOUNDED if walk costs to it can be made arbitrarily negative. Walks may repeat vertices and edges. Unbounded cost requires a negative-total directed cycle that is reachable from 0 and can reach that vertex. A cycle in an unreachable component does not affect reachable distances; a nonnegative cycle never creates unbounded cost. The source itself normally has finite cost 0 unless such a negative cycle can lead back to it. Parallel edges and self-loops are permitted. For n=0, return []. Finite output strings have no plus sign or leading zeroes except 0. Use wide signed arithmetic in Java/C++.
