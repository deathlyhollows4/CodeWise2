The array next defines a directed functional graph: vertex i has exactly one outgoing edge to next[i]. Return one pair per vertex i, in vertex order: [cycleLength,distanceToCycle]. Following successors forever from i eventually repeats a cycle. cycleLength is the number of distinct vertices in that eventual cycle. distanceToCycle is the number of edges from i until first reaching a cycle vertex; it is 0 when i already lies on a cycle. A self-loop is a cycle of length 1. The graph can have multiple disconnected cycles and many tails merging into them. An empty array returns []. Compute results for every vertex, aiming for O(n) total time rather than restarting a long pointer walk for every vertex. Classify every disconnected component and every tail, including starts that eventually reach the same cycle.
