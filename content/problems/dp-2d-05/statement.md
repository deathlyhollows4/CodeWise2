Choose some positions from ASCII string source in strictly increasing index order. Count how many position selections spell ASCII string target exactly, modulo 1000000007. Different selected positions count separately even when the selected characters are equal. You may skip source characters, but cannot reorder them or use a position more than once. The empty target has exactly one selection: choose no positions. A target longer than source has no selection. Matching is literal and case-sensitive, including spaces, punctuation and control characters. Return the number of selections, not the number of distinct resulting string values.
