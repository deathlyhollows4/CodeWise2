An array dimensions describes a chain of matrices. If dimensions has length n+1, matrix i has dimensions[i] rows and dimensions[i+1] columns. Multiply all n matrices in their original order, choosing parentheses to minimize scalar multiplication work. Multiplying an x by y matrix by a y by z matrix costs x*y*z scalar multiplications and produces an x by z matrix. Return the minimum total work. You may not reorder matrices. No actual matrix entries are supplied or needed. With fewer than two matrices, no multiplication is needed and the answer is 0; an empty dimensions array also returns 0. Use a 64-bit integer accumulator in Java/C++.
