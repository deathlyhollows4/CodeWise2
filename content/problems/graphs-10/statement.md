A directed multigraph has vertices 0 through n-1. The row edges[id]=[u,v] is original edge id, directed from u to v. Return any sequence of original edge IDs that uses every edge exactly once and forms one continuous directed trail: the end vertex of one chosen edge must equal the start of the next. You may start at any vertex. Vertices and edges may be revisited only as allowed by unused edge occurrences; an original edge may never be reused. Parallel edges and self-loops are permitted and retain their separate IDs. Isolated vertices do not need to be visited. If no such trail exists, return exactly [-1]. With no edges, return []. The checker accepts every valid edge-ID trail; output order need not be the same as the reference. Edge-list order defines IDs and therefore is meaningful.
