A rectangular grid has rows sorted from left to right and columns sorted from top to bottom, both in nondecreasing order. Return true if target occurs anywhere, otherwise false. Duplicates are allowed. Rows may overlap in value range: the next row need not start after the previous row ends. An empty grid or a grid with zero columns contains no target. Do not flatten and assume a globally sorted list. Aim for O(rows+columns) search. Local decoded input arrays may be modified; only the returned result is graded.
