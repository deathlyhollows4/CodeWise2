Split the entire text into consecutive nonempty pieces, each a palindrome. Return the smallest number of cuts between pieces. Every character must belong to exactly one piece, in order. A partition with k pieces has k-1 cuts, so a nonempty whole-text palindrome needs 0 cuts. The empty text also needs 0 cuts. Matching is literal and case-sensitive for ASCII characters. Return cuts, not the number of pieces, the longest palindrome length, or a list of pieces. Choosing a locally longest palindrome is not a proof of an optimal global partition.
