One machine handles jobs one at a time. With integer rate r >= 1, a job with work w uses ceil(w/r) whole clock slots. Unused capacity in its final slot cannot carry into another job. After every job except the last, the machine must pause for exactly pause slots. There is no pause before the first job or after the last. Return the smallest integer rate that finishes all jobs within deadline slots. Return -1 if no rate can meet the deadline. For no jobs, return 0. Do not combine the work of different jobs before rounding. Local decoded input arrays may be modified; only the returned result is graded.
