An implicit table has the given number of rows and columns. Cell (i,j), counting from 1, contains i*j. Imagine sorting all cell values, keeping repeated values from different cells as separate entries. Return the kth value, counting from 1. Do not construct or sort the full table: it can contain ten billion cells. Equal products still occupy separate ranks. Return a 64-bit integer value. The input always satisfies 1 <= k <= rows*columns.
