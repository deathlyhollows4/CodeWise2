There are n stops numbered 0 through n-1. The square matrix costs gives the nonnegative directed cost of travelling directly from stop i to stop j. Start at stop 0, visit every other stop exactly once in some order, and return directly to stop 0. Return the minimum total cycle cost. For n=0 or n=1, return 0 because no travel is needed. Costs need not be symmetric and need not obey a triangle inequality. A zero cost is a free edge, not a missing edge. Every direct edge is available. Diagonal entries are ignored because the route does not travel from a stop to itself. Do not revisit intermediate stops or replace a direct edge by an arbitrary shortest path. Return a 64-bit integer in Java/C++.
