Process commands in order. add inserts the given nonnegative handle at its priority only when that handle is inactive; adding an already active handle does nothing. cancel removes that handle if active. pop removes and returns the active task with the largest priority; tied priorities return the task added successfully earliest. Return one handle per pop, or -1 for an empty queue. An inactive handle may be reused by a later add, which creates a new task with a new arrival order. priorities are ignored for cancel and pop; ids are ignored for pop. There is no priority-update operation.
