Return true if the entire text can be split into one or more consecutive dictionary words, and false otherwise. Every character must be covered exactly once, in order, without overlaps or gaps. You may reuse a dictionary word any number of times. Dictionary order does not affect the answer. Matching is literal and case-sensitive, including spaces or punctuation. The empty text returns true because an empty token sequence covers it. A nonempty text and empty dictionary return false. Dictionary words themselves are never empty.
