Vertices 0 through n-1 are tasks. An edge [u,v] means task u must appear before task v. Return any ordering of every vertex exactly once that respects every edge. If no such ordering exists, return an empty array. An empty graph also returns an empty array. Self-dependencies are allowed and make a nonempty graph impossible to order. No duplicate directed edges occur. Disconnected tasks and isolated vertices must still appear. The checker accepts every valid ordering, so you do not need the lexicographically smallest one.
