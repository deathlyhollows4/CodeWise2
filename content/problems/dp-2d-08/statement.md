Return true if pattern matches all of ASCII string text. In pattern, ? matches exactly one ASCII character and * matches any number of characters, including zero. Every other pattern character matches itself literally and case-sensitively. A match must consume the entire pattern and entire text. Consecutive stars are allowed and behave like one star. There is no escape syntax: every * or ? in pattern is a wildcard, and a backslash is an ordinary literal character. Characters in text are always literal, even * and ?. Spaces, punctuation and control characters are valid ASCII characters. This is wildcard matching, not a regular-expression language.
