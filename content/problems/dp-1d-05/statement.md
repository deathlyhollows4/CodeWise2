Codes 1 through 26 stand for the letters A through Z. A message is a string of decimal digits without separators. Count the ways to split the entire string into valid codes. A token may have one or two digits, must be in 1..26, and must not start with 0. Return the count modulo 1000000007. The empty message has no decoding and returns 0. Different token boundaries are different decodings even if individual letters repeat. Do not enumerate all splits of a long message.
