values[i] is the maximum forward jump length allowed from index i. Start at index 0 and reach the last index using as few jumps as possible. From i you may land at any later index j with j-i <= values[i]; a jump cannot land outside the array. Return the minimum number of jumps, or -1 if the last index cannot be reached. Empty input and a single position both return0 because no move is required. A zero entry permits no forward jump from that position. You may jump over zero entries. Return a jump count, not just whether the goal is reachable.
