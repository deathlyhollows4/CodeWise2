There are n sites numbered 0 through n - 1. Each row [u,v,cost] in edges offers an undirected connection costing cost. Choose connections that link every site into one connected network, and return the smallest possible total cost. Return -1 if connecting all sites is impossible. You may ignore self-loops and may choose among parallel connection offers separately. Costs are nonnegative. With zero or one site, return 0. Edge order and swapping the two endpoints of an offer do not change the task. Return a 64-bit integer in Java/C++ because the total can exceed 32-bit range. You do not need to return the chosen edges.
